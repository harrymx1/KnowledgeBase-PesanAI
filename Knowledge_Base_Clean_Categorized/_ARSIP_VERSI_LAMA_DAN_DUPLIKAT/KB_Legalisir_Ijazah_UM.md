## Legalisir Um)

**A. Tutorial / Tata Cara**

Langkah-langkah umum melakukan legalisir ijazah elektronik
1. Menyiapkan dokumen ijazah asli, akta asli (jika ada), dan transkrip asli
2. Membuat akun di legalisir.um.ac.id
3. Mengunggah/upload scan ijazah, akta, dan transkrip akademik
4. Menunggu hasil validasi dari admin legalisir UM
5. Membayar biaya legalisir ke nomor akun yang telah ditentukan
6. Mengunduh file PDF yang telah dilegalisasi oleh Peruri

**A. Ketentuan Penyiapan Dokumen Scan**

- Scan dokumen wajib menggunakan mesin scanner (tidak diperkenankan menggunakan HP atau aplikasi
Camera Scanner)
- Format file harus JPG/JPEG (file PDF tidak diperkenankan)
- Gunakan resolusi tinggi, hasil scan harus bersih, tajam, dan besar file tidak lebih dari 2 MB per file
B. Cara Membuat Akun
1. Buka link legalisir.um.ac.id
2. Jika NIM Anda terdaftar dalam database UM, buat akun permohonan legalisir dengan memasukkan email aktif
dan membuat password baru (bukan password email)
3. Lakukan verifikasi akun melalui email aktif yang digunakan saat pendaftaran
4. Login ke akun legalisir yang sudah dibuat
C. Cara Mengunggah Scan Dokumen
1. Unggah scan Ijazah, Akta, dan Transkrip pada kolom/tombol yang sesuai
2. Kirim file scan berkas
D. Proses Validasi Admin
1. Setelah unggah berkas, cek status pengajuan legalisir secara berkala karena admin akan memverifikasi berkas
2. Jika pengajuan ditolak, akan muncul pemberitahuan status penolakan — perbaiki berkas yang dinyatakan belum
tepat, lalu unggah ulang ke sistem
E. Biaya dan Pembayaran
Biaya legalisir untuk dokumen Ijazah dan Transkrip adalah Rp50.000 per jenis dokumen, sedangkan biaya legalisir
Akta Mengajar adalah Rp30.000. Masa berlaku e-Legalisir adalah 6 (enam) bulan terhitung sejak tanggal
ditandatangani.
Cara Pembayaran
Setelah pengajuan berkas disetujui oleh admin, pemohon perlu melakukan pembayaran sesuai kode pembayaran
(kode bayar) yang tertera pada akun legalisir. Pembayaran dapat dilakukan secara online di seluruh Indonesia
melalui beberapa bank berikut.

Rincian Channel Pembayaran per Bank
Pembayaran melalui Bank BRI dapat dilakukan lewat teller dan ATM.
Pembayaran melalui Bank BNI dapat dilakukan lewat teller, mobile banking, internet banking, dan ATM.
Pembayaran melalui Bank BTN dapat dilakukan lewat teller dan ATM.
Pembayaran melalui Bank Mandiri dapat dilakukan lewat teller, mobile banking, internet banking, dan ATM.
Pembayaran melalui Bank CIMB Niaga dapat dilakukan lewat internet banking dan ATM.
Pembayaran melalui Bank BSI dapat dilakukan sesuai ketentuan yang berlaku pada bank tersebut.
Pembayaran melalui Bank Jatim dapat dilakukan lewat teller dan ATM.
Selain melalui bank, pembayaran legalisir juga dapat dilakukan melalui Tokopedia menggunakan kode pembayaran
yang sama.
Catatan: Untuk pembayaran melalui mobile banking, saat ini hanya didukung oleh Bank BNI dan Bank Mandiri.
F. Mengunduh Hasil Legalisir
1. Setelah proses legalisir oleh admin selesai, pemohon dapat langsung mengunduh file PDF di akun masing -masing
2. File PDF dapat dicetak (hardcopy) sesuai kebutuhan
G. Cek Keaslian Dokumen via QR Code
Pemohon dapat mengecek detail data dalam QR Code menggunakan aplikasi Peruri Code Scanner (unduh di Play
Store).

B. FAQ (Frequently Asked Questions)

### Q: Bolehkah kirim foto ijazah menggunakan HP?

**A: Tidak diperkenankan menggunakan foto dari HP. File yang dikirim wajib menggunakan hasil mesin scanner.**

Variasi pertanyaan: "boleh foto pakai hp gak", "kalau scan pakai kamera hp bisa?", "apa harus pakai scanner
khusus?", "difoto aja boleh ga ijazahnya"

### Q: Bolehkah kirim file dalam bentuk PDF?

**A: Tidak diperkenankan mengirim file dalam bentuk PDF. Wajib menggunakan format JPG/JPEG.**

Variasi pertanyaan: "file nya harus jpg ya, ga bisa pdf?", "kenapa gabisa upload pdf", "format yang diterima apa
saja"

### Q: Berapa ukuran file yang diperbolehkan?

**A: Maksimal file JPEG berukuran 2 MB.**

Variasi pertanyaan: "limit ukuran file berapa", "kok gabisa upload katanya file kegedean", "batas maksimal size
foto legalisir"

### Q: Mengapa permohonan legalisir saya ditolak?

**A: Permohonan legalisir dapat ditolak karena salah satu atau lebih hal berikut: format file bukan JPEG/JPG, ukuran**

file melebihi 2 MB, file berupa foto kamera/HP (bukan hasil scan), hasil scan tidak tajam/buram/tidak terbaca jelas,
atau hasil scan miring/terpotong sebagian/tidak utuh.
Variasi pertanyaan: "kenapa pengajuan saya ditolak", "legalisir saya gagal kenapa ya", "berkas saya ga diterima
admin, kenapa", "status ditolak artinya apa"

### Q: Mengapa saya gagal melakukan pembayaran?

**A: Setiap bank memiliki cara/aturan pembayaran yang berbeda-beda. Pastikan Anda sudah membuka dan mengikuti**

panduan cara pembayaran sesuai bank yang digunakan.
Variasi pertanyaan: "bayar legalisir kok gagal terus", "kode bayar ga bisa dipakai", "gimana cara bayar legalisir
yang benar", "pembayaran saya error"

### Q: QR Code legalisir tidak bisa/tidak dikenali oleh aplikasi scanner yang saya unduh?

**A: QR Code hanya dapat dipindai menggunakan aplikasi Peruri Code Scanner yang dapat diunduh di Play Store.**

Variasi pertanyaan: "qr code nya ga kebaca pakai aplikasi lain", "cara cek keaslian ijazah legalisir gimana",
"aplikasi apa buat scan qr code ijazah"

### Q: Berapa lama masa berlaku e-Legalisir?

**A: Masa berlaku e-Legalisir adalah 6 (enam) bulan sejak tanggal ditandatangani.**

Variasi pertanyaan: "legalisir berlaku sampai kapan", "expired ga legalisir online ini", "masa berlaku e -legalisir
berapa bulan"

### Q: Berapa biaya legalisir ijazah?

**A: Biaya legalisir Ijazah/Transkrip Rp50.000 per jenis dokumen, dan Akta Mengajar Rp30.000.**

Variasi pertanyaan: "legalisir bayar berapa", "biaya legalisir ijazah dan transkrip berapa ya", "tarif legalisir akta
mengajar berapa"

### Q: Bank apa saja yang mendukung pembayaran lewat mobile banking?

**A: Pembayaran mobile banking untuk legalisir saat ini hanya didukung oleh Bank BNI dan Bank Mandiri.**

Variasi pertanyaan: "bisa bayar pakai m-banking gak", "mobile banking apa aja yang bisa dipakai", "bayar
legalisir lewat aplikasi bank bisa ga"

### Q: Bisakah bayar legalisir lewat Tokopedia?

**A: Bisa, pembayaran legalisir juga dapat dilakukan melalui Tokopedia menggunakan kode pembayaran yang sama**

dengan pembayaran bank.
Variasi pertanyaan: "bisa bayar pakai tokopedia?", "selain transfer bank bisa bayar dimana lagi", "ada opsi bayar
online lain ga selain bank"
